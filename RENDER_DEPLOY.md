# Deploy DocParse to Render

## Quick Deploy

1. **Push to GitHub**
   ```bash
   git add .
   git commit -m "Prepare for Render deployment"
   git push origin main
   ```

2. **Create Render Account**
   - Go to https://render.com
   - Sign up or log in

3. **Deploy from GitHub**
   - Click "New +" → "Web Service"
   - Connect your GitHub repository
   - Render will auto-detect the `render.yaml` file

4. **Set Environment Variables**
   - `OPENAI_API_KEY`: Your OpenAI API key (required)
   - `SECRET_KEY`: Auto-generated by Render
   - `DEBUG`: False (default)
   - `OPENAI_MODEL`: gpt-3.5-turbo (default)

5. **Deploy**
   - Click "Create Web Service"
   - Wait for deployment to complete

## Manual Configuration (Alternative)

If not using `render.yaml`:

1. **New Web Service**
   - Name: docparse-api
   - Environment: Python 3
   - Build Command: `./build.sh`
   - Start Command: `gunicorn docparse_project.wsgi:application --bind 0.0.0.0:$PORT`

2. **Environment Variables**
   ```
   PYTHON_VERSION=3.11.0
   SECRET_KEY=<generate-random-key>
   DEBUG=False
   OPENAI_API_KEY=<your-openai-key>
   OPENAI_MODEL=gpt-3.5-turbo
   ALLOWED_HOSTS=<your-render-url>
   ```

3. **Deploy**

## After Deployment

Your API will be available at:
- **API**: https://your-app.onrender.com/api/documents/
- **Swagger**: https://your-app.onrender.com/swagger/
- **ReDoc**: https://your-app.onrender.com/redoc/

## Update ALLOWED_HOSTS

After deployment, update your `.env` or Render environment variables:
```
ALLOWED_HOSTS=your-app.onrender.com,localhost,127.0.0.1
```

## Notes

- Free tier: Service spins down after 15 minutes of inactivity
- First request after spin-down may take 30-60 seconds
- Upgrade to paid tier for always-on service
- SQLite database resets on each deployment (use PostgreSQL for production)
